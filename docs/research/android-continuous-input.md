# Continuous input for Android public-context qualification

Decision recorded 2026-09-11: use a separate, self-target, test-only platform `Instrumentation` application for the focused API 36 body swipe. Keep PartyDeck's production APK and Godot renderer independent of this helper. Reuse the existing AGP application plugin, Java 21 and compile SDK 37.1 configuration recorded in [the toolchain research](toolchain.md); the helper's min/target API is 36, matching this qualification lane. No AndroidX test runner or new dependency/version is introduced.

The transport adds a 200 ms stationary endpoint tail while retaining the existing movement coordinates and duration. The public-context runner still owns every admission, privacy, observation, overlap, reachability and finite-budget assertion. A framework receipt cannot establish Godot processing or native recovery. A host experiment with engine processing deliberately stalled during the hold still produced release movement; native acceptance therefore remains an execution gate.

Primary platform reference: AOSP `platform/frameworks/base`, tag `android-16.0.0_r1`, resolved commit [`99b01a65cc4c104933788b3143285ab6bae65827`](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827). Source/API inspection used this exact commit and the installed public API 36 SDK. The companion qualification evidence records URL, retrieval time, encoded/decoded byte counts and hashes. The previously cached `InputShellCommand.java` was bound to the same commit's Git tree blob without downloading its content again.

The ordinary shell swipe uses one downTime and a nominal 120 Hz stream but has no post-movement stationary-tail parameter. Its `draganddrop` path adds only an initial long press. Separate `motionevent` commands do not supply this continuous stream. These facts follow from [InputShellCommand.java's frequency](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/services/core/java/com/android/server/input/InputShellCommand.java#94) and [sendSwipe](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/services/core/java/com/android/server/input/InputShellCommand.java#505).

The helper skips missed sample schedules instead of replaying catch-up bursts. It acknowledges the final endpoint MOVE, keeps the pointer there for at least 200 ms with stationary MOVEs, and attempts one terminal UP only while its device deadline remains valid. Every event is recycled. False or throwing injection makes uncertainty sticky and forbids all later input, including cleanup UP. A known local failure can release only after acknowledged DOWN, with no prior uncertainty and no earlier UP attempt. A late synchronous return cannot authorize another event. No code can promise that the OS will schedule a previously submitted operation before an absolute cutoff or that process-death cleanup runs.

The host sends only admitted physical coordinates, existing movement duration, conservative device deadlines and a random request ID. It checks correlation, fixed event identity/flags, monotonic timestamps, acknowledged DOWN freshness, at least 200 ms of tail, matching attempt/acknowledgment counts and acknowledged UP before completion. Host transport and receipt validation must finish inside the original ten-second command budget and the remaining 720-second sweep. A failed/late/interrupted completion prevents further input, UI dumps, screenshots or practice-cleanup UI. Native idle and measured half-clip overlap remain mandatory after acknowledged release.

The same-run producer binds the helper APK's bytes, actual decoded manifest and verified signer. The focused consumer reparses the original helper manifest before installing it once with `adb install -t`. It must be a self-target helper with code, testOnly enabled, backup disabled, API 36 min/target and no application components or permissions. There is no Activity launch, PartyDeck IPC/read, authority injection, fixture option or hidden-state payload in the runtime helper.
