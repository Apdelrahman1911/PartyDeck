There are important existing reuse boundaries:

- GDScript `load()` calls `ResourceLoader::load` (`modules/gdscript/gdscript_utility_functions.cpp:236`), whose default is `CACHE_MODE_REUSE` (`core/io/resource_loader.h:259`). The reuse path returns an existing live resource at `resource_loader.cpp:800–809`. Texture/font load-call counts are therefore not file-read, decode, upload or new-resource counts.
- The path cache stores raw `Resource*`, and destruction unregisters the resource (`core/io/resource.cpp:790–804,852–870`). It does not guarantee residency after the last owning reference disappears on close/reentry. During rebuild, queued old nodes can still hold references while new nodes load the same paths. A global preload would change retained-memory lifetime; it is not needed for the bounded candidate.
- `MeshInstance3D::set_mesh` retains the supplied Ref and uses its RID directly (`scene/3d/mesh_instance_3d.cpp:120–136`). A PrimitiveMesh constructor creates a server mesh (`scene/resources/3d/primitive_meshes.cpp:366–368`); its first `get_rid` builds pending arrays (`:234–238`, `_update:51–132`). Subsequent assignment of the same immutable resource reuses that mesh. Configure sizes before the first assignment; setters request rebuilds.
- Material override retains the supplied Ref (`scene/3d/visual_instance_3d.cpp:218–226`). `BaseMaterial3D::get_rid` updates shader state and lazily ensures its material RID (`scene/resources/material.cpp:3124–3127,2068–2082`). Matching material keys already share shaders (`:656–690`); the last user can release a key (`:3982–3993`). New material count is not compilation count.
- FontFile caches its TextServer RIDs/variations (`scene/resources/font.cpp:597–640,2385–2469`), and destruction clears them (`:2899–2900`). No presentation explicitly constructs a FontFile. This audit does not count text shaping, glyph rasterization or native font costs.
- `Node::queue_free` queues deletion (`scene/main/node.cpp:3461–3470`); it does not synchronously destroy the removed tree. `_ready` is first-entry gated (`:323–338`). The persistent stage is not a fresh stage every time it is reparented.
