Godot engine and Android C++ runtime notices

These files accompany Godot 4.7.2-stable and the C++ runtime distributed in the
org.godotengine:godot:4.7.2.stable Android library.

GODOT_LICENSE.txt
  The unchanged upstream Godot MIT license.

GODOT_COPYRIGHT.txt
  The unchanged upstream Godot third-party copyright and license notices,
  including Mozilla attribution and the full MPL-2.0 text.

ANDROID_NDK_LLVM_NOTICE.txt
  The complete, unchanged LLVM toolchain NOTICE from Android NDK r29
  (29.0.14206865). It includes the Apache License 2.0 with LLVM Exceptions and
  supplemental libc++ and libc++abi notices for the distributed C++ runtime.

GODOT_CA_CERTIFICATES_SOURCE.txt
  How to obtain the Mozilla CA certificate bundle source included in Godot,
  with a pinned download URL, source commit, size, and SHA-256 hash.

GODOT_CA_BUNDLE_SOURCE.txt
  An offline copy of that source, provided under MPL-2.0. Its bytes are unchanged
  from Godot's thirdparty/certs/ca-bundle.crt; only its filename has changed.

NOTICE_PROVENANCE.json
  Original paths, pinned sources, hashes, and the verified Android library and
  NDK package provenance for these notices and the CA source.

Shared fonts have separate notices in the renderer's assets/licenses/ directory.
Android host dependencies have their own notice inventory.
